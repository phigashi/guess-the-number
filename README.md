# 数当てゲーム (Number Guessing Game)

Pythonの基礎構文（`for`ループ、`try-except`例外処理、`for...else`構文）を使って作成した、シンプルで遊べる数当てゲームです。

## 🎮 遊び方
1. プログラムを実行すると、1から100までのランダムな数字が一つ秘密裏に選ばれます。
2. 1〜100の間の数字を予想して入力してください。
3. 最大 **10回** まで挑戦できます。
4. 入力した数字のヒント（「もっと小さい数字です」「もっと大きい数字です」）を頼りに正解を目指します。
5. **注意**: 整数以外の文字を入力した場合、エラーとなり **1回分が消費されます**。

## 💻 実行方法
ターミナル（コマンドプロンプト等）で、ファイルが保存されているディレクトリに移動し、以下のコマンドを実行してください。

```bash
python guess.py
